# 二年级学习乐园

一个给二年级小朋友做的 **GitHub Pages 学习网站**，数学、语文、英语、科学四大板块，边玩边学。
纯静态 HTML（单文件、无依赖），PC / iPad / 手机浏览器都能直接打开。

## 在线访问

<https://liujiyong7.github.io>

## 首页功能

- **学科筛选**：全部 / 数学 / 语文 / 英语 / 科学，带数量统计
- **最近学习**：用 localStorage 记住最近打开的 5 个项目
- **随机来一局**：🎲 随机打开一个练习
- **响应式**：手机 1 列、iPad 多列、PC 宽屏自适应

每个练习页顶部都有统一的「🏠 首页」导航条，方便随时回到首页。

## 新增一个练习页面

1. 把新的 html 文件放到仓库根目录，页面里加一条返回首页的链接即可：
   ```html
   <a href="index.html">🏠 首页</a>
   ```
2. 在 `index.html` 的 `APPS` 数组里加一项（文件名建议用 URL 编码，避免中文路径问题）：
   ```js
   { file:"新页面.html",
     title:"页面标题", icon:"🎯", subject:"math",
     desc:"一句话介绍。", tags:["标签1","标签2"] },
   ```
   `subject` 取值：`math` / `chinese` / `english` / `science`。
3. 提交推送后 GitHub Pages 会自动更新。
